Drone XP Racing

Virtual Reality app for Meta Quest.

Project Information

Company: Plan XP Marketing Digital Ltda
Platforms: Meta Quest
Team Members: One other Unity developer, one UI/UX artist
My Role: Unity Developer

  • Project architecture and workflow design
  • UI implementation
  • Helped in drone gameplay and rings placement with tweaks and optimization
  • Implemented the circuits system that allows the user to load and save their rings setups
  • Implemented the Unity's localization package system for the three language options of the app

A free, simple game designed to expand PlanXP's portfolio and demonstrate the company's VR development capabilities.
Players control a drone through rings in a virtual environment using Meta Quest controllers. The ring layout is fully customizable, as users can position each ring themselves.

On the Meta Quest 3, Mixed Reality (MR) allows game elements to be overlaid onto the user's real-world environment, which is scanned by the device's cameras. The headset natively detects walls, ceilings, floors, and other surfaces, using them as collision points that affect the drone's movement.

When I worked on this project I was given a Meta Quest 2 for testing which unfortunately is incapable of running the MR mode of the game.
Because of that, all the subsequent videos on this page were recorded inside the VR mode of the game instead which puts the user inside a virtual room environment that works the same exact way as the MR mode but without the camera feed of the real world in the background.

Menus of the game.
Localization was implemented using a Unity package that manages all in-game text.
The system uses separate string tables for each supported language, with every UI element text linked to a specific entry. When the user changes the language, all text is automatically replaced with the appropriate translation.

Drone flying demonstration where I helped with tweaks and optimizations.
The drone can fly freely by using the analog sticks of the Meta Quest. A First Person view camera can be toggled on to be able to see what the drone sees.

Another feature I helped tweak, ring placement.
It's possible to place rings in the environment and the drone can fly through them.
It's mandatory to fly through all rings in order, starting at the Start ring all the way to the Finish ring.

Circuits feature I implemented.
The user can access the Circuits menu to save the current ring layout or load a previously saved layout.
A json file is created or loaded, containing the current position and rotation of all rings and any pertinent data which is then applied to the current layout.

This app is free and available on the Meta Quest Store. It works on any Meta Quest headset, but the Mixed Reality (MR) features are exclusive to the Meta Quest 3. Older models will run the experience in standard VR mode.
